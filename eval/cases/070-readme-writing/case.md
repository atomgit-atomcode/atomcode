当前目录有一个 `wordcount.py` 的小工具但没有 README。
请创建 `README.md`，至少包含以下章节：
- Title（项目标题）
- Overview（一句话说它做什么）
- Usage（至少一个命令行例子）
- Example output（示例 + 预期输出）
- Requirements（Python 版本要求等）

你需要**先读 wordcount.py 理解它真正的行为**，不要凭空编造（例如，你要准确描述它的参数）。
README 应该能让第一次看到的人 30 秒内上手。

无需运行验证，生成完整的 README.md 即可。
