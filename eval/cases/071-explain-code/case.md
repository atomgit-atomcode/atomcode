目录下有一个 `mystery.py`，请阅读它的源码，然后写一个 `EXPLANATION.md`，回答：

1. **What it does**（一句话总结它整体的功能）
2. **Algorithm**（用 3–5 句中文解释它背后的算法/思路）
3. **Complexity**（时间复杂度和空间复杂度，用大 O 表示）
4. **Edge cases**（列出至少 2 个需要注意的边界情况）
5. **Example**（给一个输入输出的例子）

注意：不要运行它，只读代码回答。不要编造行为（例如，如果函数里没处理某种情况，就诚实地写"未处理"）。
