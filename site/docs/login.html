登录方式

AtomCode 支持三种方式接入 LLM:AtomGit CodingPlan(含免费额度)、纯 OAuth 登录、以及传统 API Key。本页帮你选对方式,并完成绑定。

三种方式速览

方式命令适合人群
AtomGit CodingPlan/codingplan推荐 — 一条命令登录 + 申领免费额度 + 自动配好 provider 和 model
纯 OAuth 登录/login只想完成身份认证,不绑定 CodingPlan(高级用法)
API Key/provider 或手动编辑配置使用自有 OpenAI / Claude / DeepSeek Key 的用户

AtomGit CodingPlan(推荐)

AtomGit 是 CSDN / 开放原子开源基金会旗下的开源代码托管平台,AtomCode 原生集成了它的 OAuth 和 CodingPlan。/codingplan 是新用户最省事的入口,一次操作完成登录 → 申领免费 token 额度 → 自动根据额度内的模型列表写好 provider 配置。用完这条命令,直接就能开始聊天。

从首次运行欢迎界面接入

  1. 首次启动 atomcode,会进入欢迎界面。
  2. 用方向键选中 Set up CodingPlan · Free tokens · recommended,回车。
  3. 浏览器会自动打开 AtomGit 授权页面,点击允许即可。
  4. 授权完成后 TUI 会自动申领 CodingPlan 并写入 provider 配置,无需再动 config.toml,直接开始发消息。

在已有会话里接入

已经进入 TUI 后,任意时刻执行:

/codingplan

会唤起浏览器完成授权、申领 CodingPlan、更新 provider 列表。再次执行会重新同步模型列表,把本地的 AtomGit* provider 同步到最新的额度模型。

从命令行接入

atomcode codingplan

适合在脚本、远程服务器、容器镜像等场景一次性完成接入。CLI 子命令和 TUI /codingplan 走同一套流程,输出同样的报告。

只做身份登录(不绑定 CodingPlan)

如果你已经用 API Key 配好了 provider,只需要完成 AtomGit 身份认证以便使用 /issue 等 AtomGit 集成功能,可以单独执行:

/login        # TUI 里
atomcode login  # 命令行

/login 只做 OAuth 身份认证,不动 provider 配置,也不申领 CodingPlan。

查看状态 / 退出

atomcode status     # 或 TUI 内 /status — 包含 CodingPlan 使用量和过期时间
atomcode logout     # 或 TUI 内 /logout — 清除 OAuth token

API Key 方式

如果你想使用自有的 OpenAI / Claude / DeepSeek / GLM 等密钥,有三种做法:

方式 A:TUI 内 /provider

  1. 在 TUI 中输入 /provider。
  2. 选择"添加新 provider",按提示填写 type、base URL、API Key、model 等。
  3. 配置会自动写回 ~/.atomcode/config.toml。

方式 B:手动编辑配置文件

直接编辑 ~/.atomcode/config.toml,写入一个 [providers.*] 条目即可,字段参见 ProviderConfig 字段。

方式 C:命令行一次性覆盖

不想改配置文件、只想临时用另一个 provider?启动时加参数即可:

atomcode --provider deepseek --model deepseek-reasoner

选哪个?

  • 第一次使用 → CodingPlan(/codingplan),免费额度直接用。
  • 只要身份 + 已有 API Key → 纯 /login,不改 provider。
  • 需要在 CI / 脚本里跑 → API Key + 配置文件或环境变量。
  • 完全离线 → 配置一个 Ollama provider,不需要任何登录。
