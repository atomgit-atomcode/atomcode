WebUI 界面

除了终端 TUI，AtomCode 还内置一个浏览器界面：在 TUI 里输入 /webui 即可一键启动，在浏览器里聊天、翻看历史会话、增删改模型配置、上传图片，并通过 /sync 让终端与浏览器实时同步同一个会话。它复用本机的登录态、模型与会话历史，不需要另外配置。

上下文压缩后，保留的历史用户消息会标注“非新指令”。点击会话顶部的“查看完整历史”可阅读原始回合、推理与工具记录，不会改变当前任务或输入草稿。刷新页面只是重新读取会话；/reload 用于重新加载配置，不等于上下文压缩。

启动与关闭

在 AtomCode 的 TUI 输入框里运行：

# 启动 webui 并自动打开浏览器（本机服务绑定 127.0.0.1:13457，手机通过中继访问）
/webui

# 关闭 webui 服务
/webui stop

启动后 AtomCode 会在本机起一个 HTTP 服务，并自动打开浏览器到形如 http://127.0.0.1:13457/?token=<一次性令牌> 的地址。URL 里带的 token 用于鉴权，等同于密码，请勿外传。同时，当前 TUI 会话会自动接入实时同步（见下文 多端实时同步）。

手机通过中继访问

webui 本地服务默认绑定 127.0.0.1，同时连接 https://relay-atomcode.atomgit.com 中继。手机扫描终端或「远程访问」面板的二维码即可访问，无需组网。仅本机使用可加 --local。详见 远程访问指南。

两种启动方式与生命周期

webui 服务跟着启动它的那个进程走，进程退出，服务就停：

启动方式什么时候停止适合
在 AtomCode 里输入 /webui运行 /webui stop，或这个 AtomCode 退出时边用终端边用浏览器，两边实时同步同一个会话
在终端运行 atomcode webui在这个终端按 Ctrl+C，或关闭这个终端窗口时只用浏览器，或把 webui 装成桌面应用来用
 
# 独立运行 webui，不依赖任何 AtomCode 终端界面
atomcode webui

# 不自动打开浏览器（脚本或桌面应用场景），只打印访问链接
atomcode webui --no-open

# 指定端口或绑定地址
atomcode webui --port 13457 --host 127.0.0.1
  • 每次启动都会生成新的令牌，旧链接随之失效，请用这次启动打印的链接打开。这条链接在本次运行期间可以在任意浏览器里使用。
  • 默认端口 13457 被占用时（比如已经有一个 /webui 在跑），会自动顺延到下一个空闲端口，以打印出来的链接为准。
  • 把 webui 安装成桌面应用（Chrome / Edge 的“安装应用”）后，服务没在运行时，打开应用会看到一个引导页，告诉你怎么启动，不再只显示浏览器的“无法访问此网站”。启动后用新打印的链接打开一次即可。

界面功能

浏览器界面把终端里的能力搬到了图形界面上，主要包括：

区域能做什么
侧边栏按项目分组的历史会话列表、搜索会话、新建对话、重命名 / 删除会话；可收起为图标栏，移动端为抽屉。
模型选择器输入框下方直接切换 provider / 模型；同名模型会附带 provider 标识消歧。
模型配置设置里管理供应商账号和账号下的多个模型，并配置协议、Base URL、API Key、上下文窗口及默认模型。
设置主题（浅色 / 深色）、语言（中 / 英）、模型配置、远程访问入口。
图片附件粘贴或选择图片随消息发送（单张上限 2MB），非视觉模型走 VL 兜底；历史里显示缩略图。
工具执行实时展示工具调用的参数与输出，可逐行展开查看，历史回看同样可见。
附件菜单（+）上传图片、选择文件作为上下文、插入技能（Skills）。
工作目录切换工作目录、浏览目录、新建文件夹、设为默认工作目录。

管理工作区列表

在侧边栏工作区目录右侧，+ 前的菜单提供“置顶工作区 / 取消置顶”“清空会话”和“移除工作区”。置顶和隐藏状态保存在本机服务端，刷新或重启后仍然保留。

“移除工作区”仅隐藏该分组，不删除项目目录、代码或会话记录；历史仍可从“会话”视图或搜索访问。通过添加工作区重新打开该目录，可恢复展示。

“清空会话”需要确认，会永久删除该工作区列表中的会话记录，但保留空工作区和项目文件。运行中或被其他进程占用的会话不会被强制删除。如果中途失败，界面显示已删除数量并停止操作，可重试清理剩余会话。

多端实时同步

webui 背后是一个 LiveSession：同一个会话可以同时被终端和多个浏览器标签页打开，任意一端的输入、AI 的增量回复、工具调用结果都会实时广播到所有连接的视图，晚加入的一端还会先收到快照回放。

  • 运行 /webui 时，当前 TUI 会话会自动接入同步 —— 你在终端发的消息会出现在浏览器里，反之亦然。
  • 在另一个 TUI 里运行 /sync，即可接入当前正在运行的 webui 会话（需先有 /webui 在跑）。
  • /sync off —— 退出同步，回到独立会话。
  • 同步模式支持 /compact；模型切换以运行时确认结果为准，回合执行中不会切到一半。
  • 上传图片、当前工作目录和正在进行的会话会在刷新或切换视图后保留。

这让「终端里发起、手机 / 平板上盯进度」或「多人围观同一个 agent 会话」成为可能。

审批模式

底栏有一个 pill 用来设置 agent 操作的门控方式 —— 相当于终端审批模式在浏览器里的镜像。默认是 Build。

模式行为
Build(默认)交互式 —— 每次改文件、跑命令前都请求审批。
Accept Edits文件改动自动批准;命令仍需审批。
Plan只读探索 —— 写入和执行类工具被拦下,让 agent 先给方案。
Bypass(免审批)⚠ 自动批准一切,含改文件与跑命令。请谨慎使用。

该模式是进程级的,并通过实时通道广播,所以在一个标签页里切换会同步到所有已连接的视图。它不写入配置 —— 重启后回到 Build。

当 agent 在任务中途需要你拍板时,会弹出一张交互提问卡片(单选、多选或自由文本),回合会暂停到你作答为止。完整行为见 交互提问。

远程访问

在终端运行 /webui（独立启动用 atomcode webui），手机浏览器扫描中继二维码即可打开同一会话，手机和电脑可使用不同网络。完整流程见 远程访问指南。
