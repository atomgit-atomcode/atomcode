斜杠命令

在 TUI 输入框中以 / 开头即可触发命令,并获得自动补全菜单。按功能分类的 17 个内置命令如下。

核心功能

命令作用
/resume打开会话选择器,恢复任意一个之前的持久化会话(含消息、目录和模型状态)
/session创建一个全新的、干净的会话
/provider打开 provider 管理界面,增删改切换
/model在当前 provider 下切换模型,或跨 provider 切换
/login通过 AtomGit OAuth 登录,配置自动持久化到 config.toml
/cd切换工作目录,并写回 default_workdir。也可以直接输入 cd /path(无需斜杠前缀)

工具与实用操作

命令作用
/plan进入 Plan 模式(只读分析,不修改代码)。AI 会先调研、制定方案,确认后再执行
/undo回滚上一轮 AI 对本地文件的所有编辑,基于 file-history 快照
/diff显示当前工作目录未提交改动的 git diff
/cost展示当前会话输出 token 数和上下文用量。不支持 usage 报告的 API 会自动估算
/copy将 AI 最后一条回复复制到系统剪贴板
/clear清空当前会话的消息(保留工作目录和模型)
/compact压缩历史消息,把早期对话压缩成摘要以腾出上下文预算
/issue在 AtomGit 仓库上创建一个 issue(需先 OAuth 登录)

配置与帮助

命令作用
/config用默认编辑器打开 ~/.atomcode/config.toml
/status显示登录状态、当前 provider、模型、上下文预算等信息
/logout退出 AtomGit 登录
/help展示命令和快捷键参考
/quit退出 atomcode(也可以连按两次 Ctrl+C)

命令使用技巧

  • 自动补全 —— 输入 / 后会立刻弹出补全菜单,用 ↑↓ 选择,Tab / Enter 确认。
  • 模糊匹配 —— 补全支持子串匹配,比如输入 /prov 就能命中 /provider。
  • 打断正在进行的操作 —— 模型正在流式输出时按 Esc 可以打断,然后再输入新的命令或 prompt。
  • Skills 也会出现在菜单里 —— 当你在 Skills 目录中添加了自定义命令后,它们会以相同格式出现在补全菜单里。
