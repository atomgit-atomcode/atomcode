30 秒快速开始

克隆、构建、运行。就是这么简单。

从源码构建
git clone https://atomgit.com/bangxu/atomcode.git
cd atomcode
cargo build --release
cp target/release/atomcode ~/.local/bin/
首次运行 — 设置向导
$ atomcode
