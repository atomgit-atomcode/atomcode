Everything You Need

Built for developers who want Claude Code's power with any LLM provider.

⚙

Agent Loop

Autonomous multi-step execution. Read, edit, run, verify — all in a loop until the task is done.

☁

Multi-Provider

OpenAI, Claude, DeepSeek, GLM, Qwen, Ollama — connect any OpenAI-compatible API.

⚠

Safety First

Destructive commands require approval. Errors never crash — they become observations for the LLM.

🔎

Web Search & Fetch

Search the web and fetch documentation. No more "I can't access the internet".

🚀

Weak Model Optimization

3-layer JSON repair, grep literal fallback, detailed error diagnostics. Works with cheap models.

💻

Cross-Platform

macOS (ARM + Intel), Windows, Linux. Platform-aware shell, clipboard, and system prompt.

Get Started in 30 Seconds

Clone, build, run. That's it.

Build from source
git clone https://github.com/YubangXu/atomcode.git
cd atomcode
cargo build --release
cp target/release/atomcode ~/.local/bin/
First run — setup wizard
$ atomcode
