    WebUI · 桌面应用

    /webui · Chrome / Edge

    电脑上先安装 AtomCode。在系统终端运行 atomcode webui，或在 AtomCode TUI 内输入 /webui。浏览器打开后，可通过 Chrome / Edge 安装为桌面应用。
