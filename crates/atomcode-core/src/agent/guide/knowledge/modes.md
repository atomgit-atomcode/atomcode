# 模式切换

AtomCode 有三种工作模式，控制 AI 的行为边界。此外还有一个配置向导 `/codingplan`。

## /plan — 计划模式

只读探索模式。AI 只能读取和分析代码，不能修改文件或执行命令。

适用场景：
- 了解项目结构
- 分析代码逻辑
- 制定修改方案前的探索

## /build — 构建模式

完整执行模式（默认）。AI 可以读写文件、执行命令、进行所有操作。

切换方式：`/build` 切回构建模式。

## /think — 扩展思考

控制 AI 的推理深度，适用于需要深入分析的复杂问题。

| 命令 | 说明 |
|------|------|
| `/think` | 查看当前状态 |
| `/think on` | 开启扩展思考 |
| `/think off` | 关闭扩展思考 |
| `/think budget N` | 设置思考 token 预算（默认 10000） |

支持扩展思考的模型（如 DeepSeek-R1）会在回答前进行更深入的推理。

## /codingplan — 编码计划

交互式向导，从 CodingPlan 列表中选择编码任务并自动配置模型。适合首次使用或切换项目时快速初始化。
