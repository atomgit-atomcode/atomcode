# 后台任务 (/bg)

`/bg` 让你在不阻塞当前会话的情况下运行任务。适合耗时操作如批量重构、测试运行、代码生成。

## 用法

| 命令 | 说明 |
|------|------|
| `/bg <任务描述>` | 将当前会话转入后台，前台创建新会话 |
| `/bg` | 无参数：显示帮助 |
| `/bg list` | 列出所有后台任务及状态 |
| `/bg <N>` | 切换到后台槽位 N |
| `/bg drop <N>` | 终止并移除后台槽位 N |

## 工作原理

1. 当前对话保存为后台会话
2. 前台创建新的空会话
3. 后台任务独立运行，不受前台影响
4. 通过 `/bg list` 查看进度，`/bg <N>` 切回

## 限制

- 最多同时运行 4 个后台任务（`MAX_BACKGROUND_SLOTS`）
- 后台任务共享同一个 Provider 配额
- `/background <任务>` 是兼容别名，效果等同于 `/bg <任务>`
