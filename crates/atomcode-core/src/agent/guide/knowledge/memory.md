# 记忆系统

AtomCode 提供跨会话的持久化记忆功能，让 AI 在不同会话中记住重要事实。

## 命令

### /remember <内容>
保存一条记忆。记忆会在后续会话中自动注入系统提示词。

```
/remember 这个项目使用 Rust 编写，测试用 cargo test
/remember --global 我偏好的代码风格是函数式
```

- 默认保存为**项目级记忆**，仅在当前工作目录下的会话中生效
- `--global` 标记保存为**全局记忆**，所有项目共享

### /forget <关键词>
删除包含指定关键词的记忆。

```
/forget 代码风格
```

### /memory
查看所有已保存的记忆（项目级 + 全局）。

## 存储位置

- 项目级记忆：`.atomcode/memory.md`（项目根目录）
- 全局记忆：`~/.atomcode/memory.md`

记忆以 Markdown 格式存储，也可以手动编辑。

> **注意**：记忆文件以明文存储在磁盘上。请勿在记忆中保存密码、API Key、令牌等敏感信息。记忆内容仅在本地存储，不会自动上传到云端。

## 使用场景

- 记住项目的技术栈、编码规范、测试命令
- 记住用户的偏好（语言、框架、风格）
- 记住经常使用的路径、URL、配置
- 跨会话保持上下文连续性
