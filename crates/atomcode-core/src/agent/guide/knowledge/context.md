# 上下文与费用管理

## /context — 上下文预算

查看当前会话的上下文使用情况，包括各部分占用比例。

| 命令 | 说明 |
|------|------|
| `/context` | 显示上下文预算分解 |
| `/context prompt` | 显示完整系统提示词内容 |

上下文包括：系统提示词 + 项目指令 + 工具定义 + 对话历史。当对话过长时需要压缩。

## /compact — 压缩对话

压缩对话历史，释放上下文空间。AI 会保留关键信息，丢弃冗余细节。

| 命令 | 说明 |
|------|------|
| `/compact` | 自动压缩 |
| `/compact <提示>` | 按指定方向压缩（如 "保留关于数据库的讨论"） |

适用场景：对话变长、模型响应变慢、接近上下文上限时。

## /cost — Token 费用

查看当前会话的 token 使用量和估算费用。

显示内容：
- Prompt tokens（输入）
- Completion tokens（输出）
- Cached tokens（缓存命中）
- Cache hit rate（缓存命中率）
- 估算费用（USD）

## 最佳实践

- 长任务定期 `/compact` 保持上下文精简
- `/context` 检查是否接近上限
- 用 `/session` 开新会话而非在过长会话中继续
