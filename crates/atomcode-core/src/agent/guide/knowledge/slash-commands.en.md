# Slash Commands (41 total)

## Account
- `/login` — AtomGit OAuth login
- `/logout` — Sign out
- `/whoami` — View current user

## Session
- `/clear` — Clear screen
- `/session` — New/switch session
- `/rename` — Rename current session
- `/resume` — Restore previous session
- `/compact` — Compress conversation history
- `/context` — View context usage
- `/cost` — View token costs

## Model & Configuration
- `/model [name]` — Switch model
- `/provider [name]` — Switch provider
- `/config` — Open config file
- `/reload` — Reload configuration
- `/language` — Switch UI language
- `/setup` — First-time setup wizard
- `/upgrade` — Upgrade atomcode

## Workflows
- `/bg <task>` — Background task execution (alias: /background)
- `/diff` — View git diff
- `/undo` — Undo last modification
- `/cd <dir>` — Change working directory
- `/init` — Initialize project instruction files
- `/worktree` — Git worktree isolation
- `/plan` — Planning mode (read-only exploration)
- `/build` — Build mode (full execution)
- `/think [on/off/N]` — Extended thinking control
- `/codingplan` — Coding plan

## Memory
- `/remember <content>` — Save fact to memory (--global for global)
- `/forget <keyword>` — Delete matching memories
- `/memory` — View all memories

## Extensions
- `/skills` — Browse installed skills
- `/plugin` — Plugin marketplace (install/uninstall/list)
- `/mcp` — MCP server status
- `/paste` — Paste clipboard image

## Help
- `/help` — Show all commands
- `/guide <question>` — Ask the guide
- `/keys` — Keyboard shortcuts
- `/issue` — Report bug / request feature
- `/welcome` — First-time onboarding
- `/status` — Session status
- `/quit` — Exit
