# Slash 命令参考

## 帮助类
- `/help` — 显示帮助
- `/guide <问题>` — 向 atomcode-guide 提问使用方法

## 会话类
- `/clear` — 清空对话
- `/compact` — 压缩对话历史
- `/context` — 查看上下文使用情况
- `/resume` — 恢复之前的会话
- `/session` — 会话管理

## 设置类
- `/model [model]` — 切换模型
- `/provider [provider]` — 切换 Provider
- `/config` — 打开配置
- `/keys` — 快捷键参考

## 工作流类
- `/bg <任务>` — 后台执行任务
- `/diff` — 查看变更
- `/undo` — 撤销上次操作
- `/cd <目录>` — 切换工作目录
- `/init` — 初始化项目 CLAUDE.md
- `/worktree` — 创建 git worktree
- `/plan` — 进入计划模式

## 插件和扩展
- `/mcp` — MCP 管理
- `/skills` — 技能管理
- `/plugin` — 插件管理
