# 会话管理

AtomCode 的会话自动持久化到磁盘，支持随时恢复和切换。

## 命令

### /session
新建会话。清除当前对话历史，显示欢迎界面。旧会话保留在磁盘上，可通过 `/resume` 恢复。

### /resume
恢复之前的会话。弹出会话选择器，显示所有历史会话及其消息数。选择后加载完整对话历史。

### /rename <名称>
重命名当前会话。名称用于在会话列表中识别。

```
/rename 数据库重构讨论
```

## 会话存储

会话文件保存在 AtomCode 的数据目录中，按工作目录分组。每个会话包含完整的对话历史、时间戳和消息计数。

## 典型工作流

1. 开始新功能：`/session` 开始新会话
2. 中途需要切换：直接 `/resume` 选择之前的会话
3. 给会话命名：`/rename feature-auth` 方便以后找
4. 会话过长：`/compact` 压缩或 `/session` 重新开始
