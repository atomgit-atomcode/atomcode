# 故障排除指南

## Provider 连接失败

**症状**: 提示 API 连接错误或认证失败。

**排查步骤**:
1. 检查 API Key 是否正确: `/config` 查看当前配置
2. 确认 `base_url` 是否可访问（企业网络可能需要代理）
3. 检查 Provider 服务状态是否正常
4. 尝试切换 Provider: `/model` 选择其他模型

## 模型响应超时

**症状**: 发送消息后长时间无响应。

**排查步骤**:
1. 检查网络连接是否稳定
2. 尝试切换到更快的模型（如 Haiku）
3. 使用 `/clear` 清空上下文后重试
4. 检查 Provider 是否有速率限制

## 命令无响应

**症状**: 输入斜杠命令后没有反应。

**排查步骤**:
1. 确认命令拼写正确（输入 `/help` 查看所有命令）
2. 尝试 `/clear` 重置会话
3. 检查是否有后台任务占用资源: `/bg list`
4. 重启 AtomCode 终端

## MCP 连接失败

**症状**: MCP 工具不可用或连接错误。

**排查步骤**:
1. 检查 `mcpServers` 配置是否正确: `/mcp` 查看状态
2. 确认 npx/node 已安装且可用
3. 检查 MCP 服务器进程是否正常启动
4. 查看日志: 设置 `RUST_LOG=debug` 启动

## 文件读写权限

**症状**: 无法读取或写入项目文件。

**排查步骤**:
1. 检查 `.atomcode` 目录权限
2. 确认项目目录未被其他进程锁定
3. 检查磁盘空间是否充足

## 会话损坏

**症状**: 恢复会话时出错或内容异常。

**排查步骤**:
1. 使用 `/session` 新建会话
2. 如需清理: 删除 `.atomcode/sessions/` 下的损坏文件
3. 使用 `/resume` 尝试恢复其他会话

## LSP 不工作

**症状**: 代码补全、跳转定义等功能不可用。

**排查步骤**:
1. 确认语言服务器已安装（如 rust-analyzer、typescript-language-server）
2. 检查 `lsp.enabled` 配置: `/config`
3. 查看 LSP 日志输出

## 更新失败

**症状**: 自动更新失败或版本不一致。

**排查步骤**:
1. 手动执行 `atomcode upgrade`
2. 检查网络连接和代理设置
3. 如遇权限问题: 使用管理员权限运行

## Guide 查询无响应

**症状**: 输入 `/guide <问题>` 后长时间无回答或报错。

**排查步骤**:
1. 确认已配置 Provider: `/config` 检查是否有可用的模型
2. 检查网络连接（Guide 子代理可能需要 web_fetch 拉取在线文档）
3. 尝试简化问题重新查询（如 `/guide 怎么切换模型`）
4. 如果问题持续，重启 AtomCode 后重试
5. 直接访问文档站: https://atomcode.atomgit.com/docs/zh/

## 获取更多帮助

如果以上方案都无法解决问题:
1. 使用 `/guide <具体问题描述>` 获取针对性帮助
2. 访问文档站: https://atomcode.atomgit.com/docs/zh/
3. 提交 Issue: 使用 `/issue` 命令提交 bug 或功能请求
