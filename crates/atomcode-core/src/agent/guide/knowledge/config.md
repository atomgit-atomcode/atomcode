# 配置参考

## 配置文件位置
- 全局配置: `~/.atomcode/settings.json`
- 项目配置: `.atomcode/settings.json`

## 主要配置项
- `model` — 默认模型
- `provider` — 默认 Provider
- `permissions` — 权限模式
- `mcpServers` — MCP 服务器
- `hooks` — 钩子配置

## 项目指令文件
- `CLAUDE.md` / `ATOMCODE.md` — 项目指令
- `AGENTS.md` — Agent 行为配置
- `.atomcode.user.md` — 用户指令
