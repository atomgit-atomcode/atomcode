浏览器通知能力探针（Notification API Probe）

用途：验证 localhost secure context 下 Web Notification API 的权限流与弹窗行为， 与 atomcode 代码无关。用任意 localhost 静态服务器托管本页即可： python3 -m http.server 8080 后访问 http://127.0.0.1:8080/scripts/notify-probe.html。
