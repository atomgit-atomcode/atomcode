## Semantic Searcher 内部架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      Semantic Searcher                           │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │                  Language Registry                          │ │
│  │                                                            │ │
│  │   file_ext ──▶ (Language, Grammar, QuerySet)               │ │
│  │                                                            │ │
│  │   ┌───────┐ ┌────────┐ ┌────┐ ┌────┐ ┌────┐ ┌───┐ ┌───┐│ │
│  │   │ Rust  │ │ Python │ │ JS │ │ TS │ │ Go │ │ C │ │C++││ │
│  │   │.rs    │ │.py     │ │.js │ │.ts │ │.go │ │.c │ │.cc││ │
│  │   └───┬───┘ └───┬────┘ └──┬─┘ └──┬─┘ └──┬─┘ └─┬─┘ └─┬─┘│ │
│  │       │         │         │      │      │     │     │   │ │
│  │       ▼         ▼         ▼      ▼      ▼     ▼     ▼   │ │
│  │   ┌──────────────────────────────────────────────────┐   │ │
│  │   │         .scm Query Files (per language)          │   │ │
│  │   │                                                  │   │ │
│  │   │   symbols.scm  ── 函数/类/结构体 签名提取        │   │ │
│  │   │   skeleton.scm ── 骨架生成（签名 + { ... }）     │   │ │
│  │   └──────────────────────────────────────────────────┘   │ │
│  │                                                            │ │
│  │   未识别后缀 ──▶ Fallback: 缩进级别分析                   │ │
│  └────────────────────────────────────────────────────────────┘ │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │                     AST Cache                               │ │
│  │                                                            │ │
│  │   HashMap<PathBuf, (Tree, ModifiedTime)>                   │ │
│  │                                                            │ │
│  │   首次解析: full parse (~100ms)                             │ │
│  │   后续编辑: incremental parse (<5ms)                        │ │
│  │   文件变更: ModifiedTime 比对，失效重解析                    │ │
│  └────────────────────────────────────────────────────────────┘ │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │                   Symbol Extractor                          │ │
│  │                                                            │ │
│  │   extract_function(file, symbol)                           │ │
│  │       → 完整函数体 + 行号范围                               │ │
│  │                                                            │ │
│  │   extract_skeleton(file)                                   │ │
│  │       → import + 签名 + { ... }，万行文件 → 200 行         │ │
│  │                                                            │ │
│  │   find_references(symbol, scope?)                          │ │
│  │       → definition + call sites + import sites             │ │
│  └────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

## 三级漏斗数据流

```
用户: "修复 calculate_tax 函数的精度问题"
                    │
                    ▼
╔═══════════════════════════════════════════════════════════════╗
║  L1: Fast Grep (ignore 库)                                   ║
║                                                               ║
║  工作区 5000 个文件                                           ║
║      │                                                        ║
║      ├── .gitignore 过滤 → 剩余 800 文件                     ║
║      ├── 文件后缀过滤 (.rs) → 剩余 120 文件                  ║
║      └── 字符串匹配 "calculate_tax" → 命中 3 文件             ║
║                                                               ║
║  耗时: <10ms        Token: 0（纯文件路径）                    ║
╚═══════════════════════════╤═══════════════════════════════════╝
                            │ 3 个文件路径
                            ▼
╔═══════════════════════════════════════════════════════════════╗
║  L2: AST 解析 (Tree-sitter)                                  ║
║                                                               ║
║  src/billing.rs (3000 行) ──▶ Parse ──▶ AST Tree             ║
║  src/tax.rs     (500 行)  ──▶ Parse ──▶ AST Tree             ║
║  src/tests.rs   (200 行)  ──▶ Parse ──▶ AST Tree             ║
║                                                               ║
║  耗时: ~50ms (3 文件)    Token: 0（AST 在内存中）             ║
╚═══════════════════════════╤═══════════════════════════════════╝
                            │ 3 棵 AST
                            ▼
╔═══════════════════════════════════════════════════════════════╗
║  L3: 语义裁剪 (Query & Slice)                                ║
║                                                               ║
║  Query: (function_item name: (identifier) @n                  ║
║          (#eq? @n "calculate_tax")) @target                   ║
║                                                               ║
║  billing.rs → 命中 fn calculate_tax() 定义 (行 64-120)       ║
║  tax.rs     → 命中 calculate_tax() 调用 (行 30)              ║
║  tests.rs   → 命中 test_calculate_tax() 测试 (行 15-45)      ║
║                                                               ║
║  耗时: <5ms          Token: ~150（3 个精准切片）              ║
╚═══════════════════════════╤═══════════════════════════════════╝
                            │
                            ▼
┌───────────────────────────────────────────────────────────────┐
│  返回给 LLM 的内容 (~150 tokens):                             │
│                                                               │
│  // Definition: src/billing.rs:64-120                         │
│  pub fn calculate_tax(amount: f64, config: &TaxConfig) -> f64 │
│  {                                                            │
│      let base = amount * config.rate;                         │
│      let rounded = (base * 100.0).round() / 100.0;  // ← bug│
│      rounded                                                  │
│  }                                                            │
│                                                               │
│  // Called from: src/tax.rs:30                                 │
│  let tax = calculate_tax(order.total, &config);               │
│                                                               │
│  // Test: src/tests.rs:15                                     │
│  assert_eq!(calculate_tax(100.0, &cfg), 5.0);                │
└───────────────────────────────────────────────────────────────┘

  对比:
  ┌──────────────┬──────────┬──────────┬──────────┐
  │              │ 传统方案  │ 新方案    │ 压缩比   │
  ├──────────────┼──────────┼──────────┼──────────┤
  │ Token        │ 60,000   │ 150      │ 400x     │
  │ 工具调用步数  │ 6-8 步   │ 1 步     │ 6-8x    │
  │ 耗时         │ ~30s     │ <0.1s    │ 300x     │
  │ LLM 注意力   │ 0.2%有效 │ 100%有效 │ 500x     │
  └──────────────┴──────────┴──────────┴──────────┘
```

## Agent Loop 数据流（v2.3.0 对比 v2.1.0）

```
v2.1.0 (当前):

  User ──▶ LLM ──▶ grep "calculate_tax"
                         │
                         ▼ 返回 3 个文件
                   LLM ──▶ read_file billing.rs
                                │
                                ▼ 3000 行截断在 2000 行 (40K tokens)
                         LLM ──▶ read_file billing.rs offset=2000
                                      │
                                      ▼ 又 1000 行 (20K tokens)
                               LLM ──▶ read_file tax.rs
                                            │
                                            ▼ 500 行全文 (10K tokens)
                                     LLM ──▶ edit_file billing.rs
                                                  │
                                                  ▼ 返回全文 (10K tokens)
                                           LLM ──▶ bash "cargo test"
                                                        │
                                                        ▼ Done

  总计: 6 步, ~80K tokens, ~45 秒

────────────────────────────────────────────────────────

v2.3.0 (目标):

  User ──▶ LLM ──▶ read_symbol billing.rs::calculate_tax
                         │
                         ▼ 完整函数 + 调用方 + 测试 (150 tokens)
                   LLM ──▶ edit_file billing.rs
                                │
                                ▼ diff + 10 行上下文 (200 tokens)
                         LLM ──▶ bash "cargo test"
                                      │
                                      ▼ Done

  总计: 3 步, ~1K tokens, ~10 秒
```
