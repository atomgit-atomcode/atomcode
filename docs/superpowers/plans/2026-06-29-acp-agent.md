# `atomcode acp` — ACP Agent Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an `atomcode acp` subcommand that runs atomcode as an Agent Client Protocol (ACP) agent over stdio, so editors/orchestrators (e.g. Zed) can drive it as one agent in a multi-agent team.

**Architecture:** A new crate `atomcode-acp` builds an ACP agent with the `agent-client-protocol` 1.0.1 builder API and serves it over `Stdio`. Per ACP session it runs a kernel-native atomcode agent via `atomcode-coding`'s `prepare → assemble → spawn`, then translates kernel `AgentEvent`s into ACP `session/update` notifications and routes the kernel's approval `Request` to ACP `session/request_permission`. The CLI gains an `Acp` command that calls `atomcode_acp::serve_stdio`.

**Tech Stack:** Rust, tokio, `agent-client-protocol = "=1.0.1"` (+ its `schema::v1` types), `atomcode-kernel`, `atomcode-coding`, `atomcode-capabilities`, `serde_json`.

## Global Constraints

- Build per-package with `CARGO_INCREMENTAL=0` — never the whole workspace (disk near-full). Example: `CARGO_INCREMENTAL=0 cargo test -p atomcode-acp`.
- `agent-client-protocol` 1.0.1 is **edition 2024 + native async closures** → toolchain must be ≥ 1.85 (verify in Task 1). `atomcode-acp` itself stays `edition = "2021"`.
- Pin the dep as `=1.0.1` (young crate, avoid API churn).
- **stdout is reserved exclusively for the ACP JSON-RPC stream.** No `println!` / `print!` anywhere in `atomcode-acp` or on the `atomcode acp` code path. All diagnostics → `eprintln!` (stderr) only. This is a review gate on every task.
- Nearly all `agent_client_protocol::schema::v1` types are `#[non_exhaustive]` — construct via their `::new(...)` builders, never struct literals.
- Wire/interop target: advertise `ProtocolVersion::V1`.

### Known unknowns the spike (Task 1) must resolve

These external-crate behaviors are not yet confirmed; Task 1 pins them and later tasks adapt:

1. **Exact handler ergonomics**: the precise signature of `responder.respond(...)`, how `cx.send_request(req).await` yields the typed response, and the exact form of the `on_receive_request!()` macro argument. The verbatim example below is the starting point.
2. **Concurrency**: whether `connect_to`'s dispatch loop runs request handlers concurrently with notification handlers (needed so a `session/cancel` arrives while a `session/prompt` handler is still awaiting). If NOT concurrent, Task 9 routes cancel via a side channel keyed by session.
3. **Test transport**: whether the crate exposes a non-`Stdio` transport (duplex/in-memory) usable for in-process integration tests. If not, Task 11 uses a spawned-subprocess-over-pipes harness.

```rust
use agent_client_protocol::schema::v1::{
    AgentCapabilities, InitializeRequest, InitializeResponse, PromptCapabilities,
};
use agent_client_protocol::{Agent, Client, ConnectionTo, Dispatch, Stdio};

#[derive(Debug, Clone, Default)]
pub struct AcpServeOptions {
    pub provider: Option<String>,
    pub model: Option<String>,
}

pub async fn serve_stdio(_opts: AcpServeOptions) -> anyhow::Result<()> {
    Agent
        .builder()
        .name("atomcode")
        .on_receive_request(
            async move |init: InitializeRequest, responder, _cx| {
                responder.respond(
                    InitializeResponse::new(init.protocol_version)
                        .agent_capabilities(
                            AgentCapabilities::new()
                                .load_session(false)
                                .prompt_capabilities(PromptCapabilities::new().image(true)),
                        ),
                )
            },
            agent_client_protocol::on_receive_request!(),
        )
        .on_receive_dispatch(
            async move |message: Dispatch, cx: ConnectionTo<Client>| {
                message.respond_with_error(
                    agent_client_protocol::util::internal_error("unhandled message"),
                    cx,
                )
            },
            agent_client_protocol::on_receive_dispatch!(),
        )
        .connect_to(Stdio::new())
        .await
        .map_err(|e| anyhow::anyhow!("acp serve failed: {e}"))
}
```

```rust
pub fn event_to_update(ev: &AgentEvent) -> Option<SessionUpdate> {
```

```rust
pub fn stop_reason(r: KStop) -> Result<AcpStop, &'static str> {
    match r {

        KStop::RateLimited => Err("rate limited"),
        _ => Err("turn ended abnormally"),
    }
}
```

```rust
use std::path::PathBuf;
use std::sync::Arc;
use atomcode_coding::config::CodingAgentConfig;
use atomcode_coding::parts::{assemble, prepare, PrepareOptions, SessionMode};
use atomcode_kernel::agent::AgentHandle;
use atomcode_kernel::provider::LlmProvider;

#[derive(Debug, Clone)]
pub struct EngineConfig {
    pub api_key: String,
    pub base_url: String,
    pub model: String,
    pub provider_type: String,
    pub context_window: u32,
    pub max_tokens: Option<u32>,
}

impl EngineConfig {
    pub fn to_coding_config(&self, cwd: PathBuf) -> CodingAgentConfig {
        let mut cfg = CodingAgentConfig::new(&self.api_key, &self.base_url, &self.model, cwd);
        cfg.context_window = self.context_window;
        cfg.chat_options.max_tokens = self.max_tokens;
        cfg.provider_type = self.provider_type.clone();
        // ACP sessions are long-lived & interactive: no per-request hard timeout.
        cfg.request_timeout = None;
        cfg
    }
}

// Copied from atomcode-bridge::runtime::build_provider (bridge is intentionally
// not a dependency). Keep the three branches in sync with that source.
pub fn build_provider(cfg: &CodingAgentConfig) -> anyhow::Result<Arc<dyn LlmProvider>> {
    use atomcode_kernel::provider::*;
    match cfg.provider_type.as_str() {
        "claude" | "anthropic" => Ok(Arc::new(AnthropicProvider::new(AnthropicConfig {
            api_key: cfg.api_key.clone(), base_url: cfg.base_url.clone(), model: cfg.model.clone(),
            // ... mirror the exact field set from bridge runtime.rs:1960-2019
            ..Default::default()
        }))),
        "ollama" => Ok(Arc::new(OllamaProvider::new(OllamaConfig {
            base_url: cfg.base_url.clone(), model: cfg.model.clone(), ..Default::default()
        }))),
        _ => Ok(Arc::new(OpenAiCompatProvider::new(OpenAiCompatConfig {
            api_key: cfg.api_key.clone(), base_url: cfg.base_url.clone(), model: cfg.model.clone(),
            ..Default::default()
        }))),
    }
}

pub async fn spawn_session(engine: &EngineConfig, cwd: PathBuf) -> anyhow::Result<AgentHandle> {
    let cfg = engine.to_coding_config(cwd);
    let opts = PrepareOptions {
        session: SessionMode::Fresh,
        skill_dirs: None,
        mcp: true,
        memory: true,
        web: true,
        review: true,
    };
    let mut parts = prepare(&cfg, opts).await
        .map_err(|e| anyhow::anyhow!("acp prepare failed: {e}"))?;
    let provider = build_provider(&cfg)?;
    let agent = assemble(&mut parts, &cfg, provider)
        .map_err(|e| anyhow::anyhow!("acp assemble failed: {e}"))?;
    Ok(agent.spawn())
}
```

```rust
    SessionId::new(format!("acp-{n}"))
}

pub async fn handle_new_session(
    engine: &EngineConfig,
    sessions: &Sessions,
    counter: &std::sync::atomic::AtomicU64,
    req: NewSessionRequest,
) -> Result<NewSessionResponse, agent_client_protocol::Error> {
    let n = counter.fetch_add(1, std::sync::atomic::Ordering::SeqCst) + 1;
    let id = new_session_id(n);
    let handle = crate::engine::spawn_session(engine, req.cwd.clone())
        .await
        .map_err(|e| agent_client_protocol::util::internal_error(&format!("{e}")))?;
    sessions.lock().await.insert(id.0.to_string(), SessionState { handle });
    Ok(NewSessionResponse::new(id))
}
```

```rust
pub fn prompt_text(req: &PromptRequest) -> (String, Vec<ImageContent>) {
    let mut text = String::new();

    for block in &req.prompt {
        match block {
            ContentBlock::Text(t) => text.push_str(&t.text),
            ContentBlock::Image(i) => images.push(ImageContent {

                data: i.data.clone(),
```

```rust
let (text, images) = dispatch::prompt_text(&req);
let sid = req.session_id.clone();
let cmd_tx = {
    let map = sessions.lock().await;
    let st = map.get(sid.0.as_ref())
        .ok_or_else(|| agent_client_protocol::util::internal_error("unknown session"))?;
    st.handle.commands.clone()
};
cmd_tx.send(atomcode_kernel::event::AgentCommand::SendMessage { text, images }).ok();

// Pump events. The events receiver lives in SessionState; take a lock per recv,
// or move the receiver out under the lock for the duration of the turn.
let stop = loop {
    let ev = { /* recv from st.handle.events */ };
    match ev {
        Some(AgentEvent::Request { id, kind, payload }) if kind == "approval" => {
            permission::handle_approval(&cx, &sid, &cmd_tx, id, payload).await?; // Task 8
        }
        Some(AgentEvent::TurnComplete { reason }) => break reason,
        Some(AgentEvent::Error { message, .. }) => {
            return Err(agent_client_protocol::util::internal_error(&message));
        }
        Some(ev) => {
            if let Some(update) = translate::event_to_update(&ev) {
                cx.send_notification(
                    agent_client_protocol::schema::v1::SessionNotification::new(sid.clone(), update),
                )?;
            }
        }
        None => break atomcode_kernel::event::StopReason::Stopped,
    }
};
match translate::stop_reason(stop) {
    Ok(sr) => responder.respond(PromptResponse::new(sr)),
    Err(msg) => Err(agent_client_protocol::util::internal_error(msg)),
}
```

```rust
    PermissionOption, PermissionOptionId, PermissionOptionKind as Kind,
    RequestPermissionRequest, RequestPermissionOutcome, SessionId, ToolCallId, ToolCallUpdate,
    ToolCallUpdateFields,

pub fn permission_options() -> Vec<PermissionOption> {
    vec![
        PermissionOption::new("allow_once", "Allow once", Kind::AllowOnce),
        PermissionOption::new("allow_always", "Always allow", Kind::AllowAlways),
        PermissionOption::new("reject_once", "Reject once", Kind::RejectOnce),
        PermissionOption::new("reject_always", "Always reject", Kind::RejectAlways),
    ]
}

pub fn outcome_to_decision(option_id: &str) -> serde_json::Value {
    match option_id {
        "allow_once" => serde_json::json!({"decision": "allow"}),
        "allow_always" => serde_json::json!({"decision": "allow", "remember": true}),
        _ => serde_json::json!({"decision": "deny"}), // reject_* and anything unknown
    }
}

pub async fn handle_approval(
    cx: &agent_client_protocol::ConnectionTo<agent_client_protocol::Client>,
    session_id: &SessionId,
    cmd_tx: &UnboundedSender<AgentCommand>,
    req_id: u64,
    payload: serde_json::Value,
) -> Result<(), agent_client_protocol::Error> {
    let tool = payload.get("tool").and_then(|v| v.as_str()).unwrap_or("tool").to_string();
    let call_id = payload.get("call_id").and_then(|v| v.as_str()).unwrap_or("").to_string();
    let tc = ToolCallUpdate::new(
        ToolCallId::new(call_id),
        ToolCallUpdateFields { title: Some(tool), ..Default::default() },
    );
    let resp = cx
        .send_request(RequestPermissionRequest::new(session_id.clone(), tc, permission_options()))
        .await?;
    let decision = match resp.outcome {
        RequestPermissionOutcome::Selected(sel) => outcome_to_decision(sel.option_id.0.as_ref()),
        _ => serde_json::json!({"decision": "deny"}), // Cancelled → fail closed
    };
    cmd_tx.send(AgentCommand::Respond { id: req_id, value: decision }).ok();
    Ok(())
}
```
