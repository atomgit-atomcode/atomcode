# 对话顶部用户消息摘要

参考 Codex tui/transcript_view/prompt_header.rs：顶部一行跟随当前阅读回合，原消息可见时不重复，小窗口不启用。

摘要只属于展示层，最多读取512字符，清理控制序列、合并空白、按终端显示宽度省略。用户原消息、事件日志、导出及模型输入保持完整。

Host 使用现有行索引定位视口上沿及其前面的可见用户消息。正文、选择坐标和滚动条共用扣除摘要后的几何；打开长工具详情时保留其标题在摘要之下。回合边界优先显示原消息，隐藏或撤回的用户消息不作为摘要来源。

测试覆盖跨回合滚动、原消息出现后取消置顶、长文本省略及控制字符、导出不重复和打开详情保持标题。
