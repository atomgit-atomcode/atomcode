# 后台会话切换直接显示最新内容

## 基线与边界

- release/v5.2.5，开始时 HEAD f20df7130，生产改动集中在 TUI 及 CLI background 路由。
- 切换时 `SessionChanged -> AgentClient::follow -> Subscribe(from=0)`；历史按事件逐条回放，屏幕每 256 个 wake 或队列暂时为空就绘制一帧。因此长历史会按回放进度刷屏，即使最终 scroll 已归底。
- 会话与日志仍由 coding runtime / harness 持有；TUI stream 是展示投影。本修复不更改模型消息、持久化格式或公共协议。
- 工作区另有输入补全相关并行改动，保留，不纳入本修复。

## 实现

1. 切换后的订阅使用已有 Tagged Subscribe 命令回执；回执在同一事件流的历史事实之后到达，作为这次回放完成的边界，不用等待时间或队列为空猜测完成。
2. TUI 在回执前折叠和保留历史，但暂停绘制中间帧；完成后归底，一次显示最新内容，之后继续正常流式绘制。
3. CLI background 同样识别带回执的订阅，打开当前前台事件 gate；如果订阅由后台问询专用路径完成，在历史和问询事件之后返回对应回执。
4. 回执按切换唯一编号匹配，旧切换的迟到回执不能解除新切换；拒绝订阅也结束等待并显示错误。事件流关闭仍由原有退出处理负责。
5. 首次启动的原有订阅行为保持；本修复覆盖实际 SessionChanged 路径，包括 /bg list、/bg N 和 /resume。

## 验证

- 为真实 TUI + background/runtime 的 /bg list Enter 切换增加长历史测试：180 个实际只读文件工具调用，超过正常绘制批次，检查帧序列不会在最新回复之前显示历史工具回放，且历史仍被保留。
- 补充迟到回执隔离和订阅拒绝释放的 TUI 回归测试。
- 运行 TUI、background 相关测试及仓库编译门；交付前检查格式与 diff。

## 验证结果

- 真实 `/bg list` Enter 长历史切换测试通过；临时移除回放绘制保护后，同一测试明确失败于“最新回复前绘制了历史”，恢复修复后通过。
- 当前订阅回执匹配、迟到回执隔离、订阅失败释放测试通过。
- CLI 与 TUI 完整 nextest：2437 passed，0 skipped。测试运行时含工作区并行的输入补全改动；本修复未修改其逻辑。
- `bash gates/compile.sh`、`cargo fmt --all -- --check`、`git diff --check` 通过。

## 提交前审计

- 订阅回执沿用现有 Tagged/Accepted/Rejected 协议，不增加 runtime 状态 owner 或持久化内容；手动重放问询的路径同样在历史和问询之后回执。
- 仅当前切换的回执能解除绘制暂停，订阅被拒同样解除；实时事件与后续回合继续使用原有绘制节流。
- 长历史回归用 current_thread/start_paused 运行并重新通过，符合异步测试的时间控制约定。
- 输入补全改动独立保留。本提交只包含后台路由、回放绘制及其回归测试。
