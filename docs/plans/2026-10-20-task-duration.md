# Task Duration Implementation Plan

**Goal:** 普通回合显示本轮耗时；活动 goal 显示 runtime 的累计耗时，自动续跑和切换视图不清零。

**Architecture:** TUI 按会话保留 HostEvent::Autonomy 的进度样本和接收时刻（重复样本不重置时刻，后台暂停/结束同步更新），不以当前视图覆盖其他会话的样本，使用注入的单调时钟补足两次进度之间的时间。普通回合使用已有 LoggedEvent.at 作为开始时间，宿主注入由启动墙钟锚点加单调时间得到的当前时间；历史记录没有时间戳时保留现有本地计时回退。普通回合输入、输出累加本轮全部请求，缓存率为累计 cached / prompt。goal 的输入、输出、缓存量由现有 runtime GoalState 在主请求和评估器的唯一 usage 接收点累计，随 GoalRunReport 检查点保存；HostAPI 可选字段传递进度与最终快照，TUI 不另建统计权威。旧检查点无历史分项时保持未知，不用当前回合伪装整个目标。

**Tech Stack:** Rust, TUI Moment/Host/live, nextest。

1. 添加注入时钟字段、目标进度来源及接收时刻，连接现有 Clock 与 took_autonomy。
2. live 耗时优先使用目标累计，普通回合从日志时间恢复；压缩与恢复等待也保持目标累计。
3. 回归覆盖自动续跑、追加输入、跨视图重放、未知时间戳、目标暂停/终止及会话隔离；运行 TUI 测试与格式检查。

目标结束提示冻结同一个累计时钟；在其他视图暂存的结束提示不继续计时。`Nailed it` 保留每回合耗时，与其回合/工具/token/本轮缓存统计一致，不把目标总耗时混入回合汇总。

目标运行行及结束提示统一使用全目标输入、输出、缓存率。结束提示优先使用 runtime 最终快照（包含最终评估），后台暂存不继续计时。底栏上下文占用仍是当前上下文；tok/s 是生成性能指标，保留当前回合的生成均速口径。
