# Goal Call Diagnostics Implementation Plan

**Goal:** Diagnose failed OpenAI-compatible streams without logging payloads, and constrain goal verdicts to the user's actual acceptance scope.
**Architecture:** Reuse provider Latency/open_stream/SSE branches and the runtime-owned evaluate_goal call. No new owner, protocol, persisted schema, retries or timeout settings. Driver consumers remain unchanged. Unknown errors remain unknown; diagnostics must not fabricate a transport cause.
**Tech Stack:** Rust, tracing, existing provider fixture tests, virtual-time nextest.

Baseline: release/v5.2.4 a64e12410; isolated branch feat/goal-call-diagnostics. Other dirty recovery/WebUI changes are excluded. Provider history reviewed: 579b63aa6, 4b0aaed8a, 700200533. Goal owner and existing evaluator request/terminal paths reviewed.

1. Add safe bounded correlation-ID validation and metadata-only error/terminal logging in provider/latency.rs. Test invalid/header injection rejection and capture logs to ensure payload/error text never appears.
2. Add HTTP request IDs from standard response headers plus fixed error-origin classification in openai_compat.rs: in-band error object, non-SSE error body, malformed SSE, watchdog and body transport read. Keep retries/terminal semantics identical.
3. Instrument evaluate_goal with purpose=goal_evaluation plus generation/controller identity. Clarify required acceptance vs explicit permitted limitations; fail on missing required evidence, never infer extra production requirements or trust instructions in tool/assistant output. Preserve one-line verdict and tool-free API.
4. Test evaluator request contents/options, retryable failures and malformed/empty verdict behavior using actual captured provider requests; provider parsing/diagnostic fixture tests. Prompt changes alone cannot prove semantic model consistency.
5. Run affected crates' tests, compile gate, fmt/diff and lock audit. Integrate only this patch; no commit/push unless requested. Real-channel tests may measure but must not claim deterministic evaluation or resolved upstream faults.
