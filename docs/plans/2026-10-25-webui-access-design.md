# WebUI 访问入口

用户确认：`/webui` 只打开本机网页；`/webui remote` 显式启用中继并显示地址及二维码；`/webui lan` 显式开放局域网并显示地址及二维码。后两者默认不打开本机浏览器，保留本机备用地址。互斥访问参数报错，不静默选择。

中继仍由 CLI 宿主管理，daemon 保存唯一对外展示地址，终端反馈、二维码及网页 `/tunnel/status` 复用同一字符串。普通 `/webui` 不再关闭已有中继；显式 stop 或宿主退出结束中继。更换监听绑定仍需先 stop，避免隐式重建 live 会话。

实测线上 protocol 1 静态网页仅识别 `#relay=...&token=...`，不识别 `#r=...&t=...`。生成端恢复共同支持的长格式；前端保留两种格式读取能力，兼容已发出的短链接。凭据仍只在 fragment，通过受保护 API 鉴权，不加入查询参数或放宽权限。代价是二维码内容增加，白边仍使用已有紧凑配置。

本地 WebUI token 不设闲置 TTL，内嵌服务器禁用 idle timeout。停止/重启后的凭据失效属于正常生命周期；不得承诺旧链接永久有效。已存在的网页访问恢复逻辑保留，旧版线上静态页面更新需独立部署。
