# 本轮生成速度与缓存统计

运行行仅显示 `x tok/s`，逻辑为本轮各次生成的 token 总量除以生成耗时总量，而非请求速度的算术平均。生成从首个非空片段开始计时，推理与正文连续累计；请求结束冻结耗时，等待下一次首 token 和执行工具不增加分母。流式期间沿用字符数 / 4 的估算，请求返回 usage 后按实际 completion 校准。没有流式计时证据时不补造测速。失败重试丢弃该次未完成估算，保留之前成功请求；新回合和会话切换清零。

运行行输入 token 保持最新请求的上下文大小；输出和缓存按本轮累计，缓存率为累计 cached / 累计 prompt，累计计数使用 u64，避免长任务超过单次请求 u32 计数范围后比例失真。底栏继续使用会话累计统计。现有 usage 无法区分“未报告缓存”和“命中为零”，沿用零值不展示的约定。

状态归 TUI Moment/Generation 和 live 投影所有，不修改 runtime、协议或事件持久化。验证覆盖多请求加权、推理转正文、usage 校准、等待/工具期间保留、重试、迟到事件、重放无测速及运行行文案。
