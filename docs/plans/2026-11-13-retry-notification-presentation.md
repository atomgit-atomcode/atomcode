# 收敛 TUI 模型重试通知

已确认的交互：自动重试次数和倒计时沿用状态栏；普通重试不逐条追加到对话区。
同一请求持续失败达到一分钟后，在下一次重试事件到达时显示一次持续失败提醒。
最终失败继续沿用红色回合终态；原始原因、次数和等待时间仍可通过 `/errors show` 展开。

边界：仅改 TUI 展示投影和 screen 文案，不改重试预算、退避、运行时所有权或持久化事件。
Transcript 从 RequestHeader 和日志时间戳折出一组重试诊断，后续结构化重试更新同一块；
回复完成、新回合或终态收起过程提醒并关闭该组，原始诊断仍可展开。没有额外计时器，重放与实时显示使用相同规则。
非结构化的断流恢复和重复思考恢复通知仍保留其原有语义。

验证：短暂失败折叠无正文、长时间失败只有一组提醒、全部原始诊断可展开、后续请求重置；
运行受影响 TUI/i18n 测试、工作区编译门、格式与 diff 检查。
