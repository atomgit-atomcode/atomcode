# 恢复终端流式生成速度

参考退役 tuix 的 phase_output_token_estimate：以四个字符估算一个 token，仅作活动指示，与服务端用量分离。生成阶段不足一秒不展示速度；推理与正文阶段、请求重试均重置，工具执行和回合结束清空。等待首片段的时间不计入生成速度。

Host 在收到实时事件时用已有注入时钟更新 Moment 的临时 Generation；模块渲染不读系统时钟、不变更事件或持久化。旧请求片段不计入当前请求。恢复历史不会凭空产生可用的生成时间。保留服务端输入/输出统计，展示为 ↑ / ↓，仅新增 tok/s 并放在缓存比例之前，不单独展示估算 token 数，沿用窄屏整项降级；删除 LiveStep 的中英文消息与展示，保留底层实际回合统计。

覆盖阶段切换、首片段等待、旧请求片段、结束清空及 live 行展示。与其他进行中的 goal/runtime 修改分开处理，不修改执行限制。
