# Browser delivery status and native integration retirement

The user has withdrawn the built-in desktop integration. `/computer`, its managed native backend integration and proprietary desktop lease protocol are being retired; the previous desktop acceptance is historical evidence only. See [current removal and automatic browser plan](2026-11-12-browser-default-and-computer-retirement.md).

The product path is `/browser` for one-time setup and ordinary natural-language webpage operations afterwards. Browser tools use the common MCP registry, native approvals, cancellation cleanup and inline image handling. Configured connections remain model-visible; browser-use static guidance is eligible for automatic loading before explicit webpage tasks. The external Node/browser backend is not bundled or downloaded implicitly, and paused connections remain paused.

The existing optional browser origin-scope/download/upload prototypes remain separately configured experimental browser extensions. Removing native desktop setup neither completes their full permission matrix nor changes their grants or filters. Historical native tests do not establish supported desktop execution on any other operating system.
