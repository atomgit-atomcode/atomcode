# 完整历史按助手轮次展示

截图中的 WebUI 是只读完整历史视图，旧实现将 TurnRecord.assistant（一个用户回合内所有模型轮次的拼接文本）直接输出到 pre，并把全部工具放在尾部 details；TUI 则在助手文字之间展示对应工具。现有数据聚合用途不同，不应把合并摘要当作原始时间线渲染。

只读接口增加可选 turn_id 及 detail 查询。普通历史导航请求保持原来的摘要形状；选中回合才读取该回合的步骤，显式查看全部时才返回全量步骤。native 会话从同一次事件日志读取同时生成原有 TurnRecord 与展示步骤，保留助手消息/PartialReply 边界；工具结果按 turn、round、call_id 配对，已批准执行的参数以 ToolStarted 为准。没有结果记录时保留 null，前端显示未完成。undone 标记继续由既有 turn_records 投影负责。

新的 steps 仅是 daemon 私有 wire DTO，不修改 TurnRecord、持久化格式、日志内容、runtime snapshot 或会话 owner。旧 JSONL 通过已有只读兼容入口读取，不猜测分步边界；旧服务没有返回步骤时也按合并内容兼容展示。提示只说明当前没有分步数据，不宣称原始日志已经丢失。

前端按步骤显示 Markdown 助手正文、可展开的推理及工具参数/结果。用户输入保持原文，工具参数和结果以转义文本展示。结果区限制高度，完整历史仍是只读，不重新发送给模型，也不替换当前时间线。导航选中后惰性加载详细数据，快速切换取消上一请求。

验证：原始助手文字和工具穿插顺序、跨轮次复用调用 ID 的结果配对、批准参数、部分回复与未完成工具；浏览器验证原始摘要不会混入步骤视图、Markdown、工具详情、撤回标记、快速切换、关闭重开、流式滚动与手机布局。
