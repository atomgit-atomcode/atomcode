# 会话滚动条显示与样式

用户已确认：缩细并降低亮度，自动隐藏闲置底部滚动条，提供显示设置。

- `[ui] scrollbar = "auto" | "always" | "hidden"`，默认 auto，下次启动生效。
- auto：浏览上方历史、拖动、或最近 800ms 有滚动操作时显示；底部闲置隐藏。
- 使用细竖线和主题的 muted 色；ASCII 终端保留 `#` 滑块与 `|` 轨道，单色环境也可区分位置。
- 隐藏时保留内容宽度，绘制与命中区域同步隐藏；平台规则一致。
- 显示状态由 TUI Moment 管理，配置经 CLI 交入 screen 行；不改会话持久化。
- 验证显示策略、配置读写、鼠标拖动及全仓编译。
