# 中文技能名称支持

已确认的范围：允许 SKILL.md 的 name、缺省名称的目录和文件名使用中文，保留已有 ASCII 名称、命名空间及 slash 转连字符行为。不更换现有调用标识。

名称由 capabilities 技能加载器校验并登记；使用 Unicode 字母和数字替代 ASCII 限制，长度按 Unicode 字符计数（1–64），保留现有分隔符规则。控制字符、零宽字符、双向控制符、空白和命令分隔符不属于新增允许字符。无效名称仍明确拒绝加载，原有含空白标题回退目录名的规则保持。

TUI 和 WebUI 斜杠命令识别同步支持中文；已有 $name 和 /skills name 网关按空白分词，无需新增调用路径。精确技能引用的边界检查同步识别 Unicode，防止子串误命中。无持久化格式、权限或 runtime 生命周期变更。

后续获确认的独立展示名：增加可选 `display-name`，默认仍展示 `name`；标题不注册为别名、不参与权限或调用解析。标题最多 128 个 Unicode 字符，非法控制或不可见字符产生警告并回退，不使合法技能失效。TUI 通过现有 summary 展示标题与说明；模型目录和 list_skills 用相同 summary，同时始终保留 name。daemon /skills 通过可选 display_name 字段提供标题，旧响应保持兼容。WebUI 的侧栏、附件菜单、斜杠菜单同时展示标题与 /name，标题和标识均可检索；选择后始终填入标识。

验证覆盖中文 frontmatter、中文目录、平铺文件、版本后缀、命名空间、参数替换、64 字符边界、非法字符、TUI $ 引用及斜杠识别、WebUI 补全及分发；最后运行受影响 crate 回归、编译门和格式检查。
