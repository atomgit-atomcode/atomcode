# 中断保留 Todo

普通中断停止当前执行，保留已记录的 Todo 内容、状态、顺序和规范引用。用户发送后续指令后才继续执行；显式 `/todo clear` 或替换清单可以丢弃旧计划。新会话不继承旧计划。

沿用 CodingRuntime 与现有取消终态，不新增运行模式、事件类型或状态所有者。Todo 从现有会话事实折取，旁挂仍为缓存。模型提示、TUI、WebUI 与持久化重建同步采用保留规则。撤销/rewind 和 keep_interrupted_context=false 的回合撤回仍排除已撤销回合，不保留被撤销的 Todo 改动。

旧事件日志按同一规则重放，因此旧会话中历史中断之前的计划也可重新展示；不修改日志或持久化 schema。旧快照内既有提示文本不重写，新中断使用保留进度的提示。

验证：Todo 折取、缓存规范引用、事件重建/撤销、TUI 重放、WebUI 未完成计划与失败/未决调用；运行受影响 crate 的相关 nextest、WebUI 类型检查、编译门与格式门。
