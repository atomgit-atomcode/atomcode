# WebUI 历史加载与会话切换反馈

基线：release/v5.2.7，6f3292447。本次只改展示与输入反馈，不改变 CodingRuntime 的运行时所有权、切换准入规则、会话格式或审批边界。

历史加载的零高度吸顶提示会叠在用户消息上。三个读取入口共用延迟 300ms 的小型加载指示器；快速读取不展示，慢读取占独立行，保留屏幕阅读器状态和减少动态效果设置。缓存读取失败不再同时保持加载态，错误及重试继续显示。

切换拒绝提示原来只在本地观察到回合终态时清除，纯空闲回放无法清除；回退时携带的副本也可能复现。现在收到权威空闲状态时同时清除两份临时提示。明确的 Busy 拒绝保持原会话，提供目标会话的显式重试，不强制取消或绕过运行时保护。实时 snapshot/session_switched 观测计数仅用于判断当前请求是否已被目标会话的权威事件确认；已确认的目标不再被迟到的 Busy 响应回退。其它租约/网络错误继续报告。手机端提示操作为浮动回合导航预留侧边空隙，避免关闭按钮被挡，也不覆盖搜索控件。

浏览器测试使用本地合成 HTTP/SSE：覆盖延迟读取不遮挡与结束后消失、完整组分页、真实拒绝与重试、没有本地回合终态的空闲回放、SSE 先确认目标而 HTTP 后返回 Busy、租约错误与 fork，以及手机/桌面反馈操作。未声称已在用户截图对应的真实 daemon 会话中复现。

交付审查：450 项 WebUI 测试、类型检查、构建、cargo fmt 检查和完整编译门通过；Chrome 回归覆盖上述切换/加载场景、过程折叠、长会话滚动、搜索复制和挂载上限。Cargo.lock 无私有 overlay 包污染；没有修改 latest.json。
