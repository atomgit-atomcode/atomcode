**共享当前终端会话**(这一轮最大的一块)。共享的意思是**同一个会话**:浏览器或手机
里看到的不是另一段对话,是这一段。做法是把当前 runtime 挂进 daemon 已有的 live hub
——和旧界面同一个 hub,所以**网页端、手机 App、IDE 插件都不用改**。

三个接点,少一个远端就看不全(`cli/src/tui_share.rs`):

1. **交出句柄**:`connect()` 接上时把句柄交给共享层。句柄不在宿主契约里——它是产品的
   东西,而 hub 拿着它才能把远端发来的话派进来;
2. **推事件**:适配器那趟循环里每条 runtime 事件都推给 hub;
3. **回显本地输入**:终端里打的字,远端是从 hub 的「输入被接受」看到的,**不是**从
   事实流——不回显,那边就只见回答不见问题。

另外两样是核 App 兼容性时查出来的(都是这一侧的错,App 没改一行):

- **手输配对串是 base64「口令」**,不是配对链接本身。二维码里装原始链接(扫码一直是
  对的),手输框收的是它的 base64——印反了,能扫的人没事、扫不了的人配不上对;
- **模式徽标要单独同步**:远端顶上的模式读的是 daemon 里的一个全局值,不是事件流。
  挂上时播种一次,之后 `ModeChanged` 到达时再同步一次。

`/desktop` 的探测(208 行)与中继客户端那套(437 行:查找、下载、校验 sha256、清单
拿不到时的兜底版本)整段从 tuix 搬进 cli:这些是产品知识,不该跟着旧界面一起没掉。
搬家时**只改了一处**——i18n 闸门不许启动器写死中文,所以四条对人说的话进了词表,
其余技术细节改成英文短句跟在后面。

**`tui_elsewhere::CLASSIC_ONLY` 现在是空的**。它是 F1 删 tuix 的前置之一:清单空了,
表示屏幕上不再有「这个功能只在经典界面里」的洞。表和判据留着——下一次真缺东西时,
那里是说清楚它在哪的地方。

## 三、这一轮踩到的

**`Cargo.lock` 的 skip-worktree 会挡住 rebase 和快进合并**,报的是
`could not detach HEAD` / `Aborting`,字面上看不出是它。办法就是 `AGENTS.md` 里写的
那套:`--no-skip-worktree` → `git checkout -- Cargo.lock` → 操作 → 设回去。每个
worktree 各设一次,主工作区也要。

**基线上的闸门本来就是红的**,不要以为是自己改红的:2026-09-22 接手时
`gates/tui.sh` 有 7 个 clippy 错误和一处 `literal_glyphs` 超标(表格框线,与 `el.rs`
同类,按同样理由豁免而不是抬基线)。此后每次同步几乎都要顺手收一笔上游漏的
`cargo fmt`——这道门是**阻塞**门,别让它积债。

**主分支推进很快**(这两天 40+ 个提交,同一批文件)。节奏是:做完一条 → rebase →
验证 → 合 → 推。撞过一次真重复(skill 命令登记),rebase 时把自己那半丢掉即可。
冲突几乎只发生在 `gates/tui-test-count.baseline`:取大的那个,再让闸门自己数一遍。

**别在验证跑着的时候改文件**:我在闸门跑到一半时写进一个带编译错的文件,整棵树编译
不过,后面每一步都跟着红,白跑一轮。

**证伪能证出真问题**。两例:`/resume` 删除时我写的「是不是当前会话」判断,摘掉之后
一个答案都没变(真正挡住它的是租约),删了;`/cd` 的判据逼出了「裸 `/cd` 拿会话 id
当路径」这个一直在的 bug。
